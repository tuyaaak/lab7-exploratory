# BUG-06: Буруу JSON хүсэлтэд сервер HTTP 200 буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Node.js, Linux (GitHub Codespaces), 2026-11-25

**Урьдчилсан нөхцөл:** `node app.js` командаар серверийг шинээр асаасан.

## Дахин гаргах алхам

1. Серверийг ажиллуулна.
2. Хоёр дахь Terminal нээнэ.
3. Дараах хүсэлтийг илгээнэ.

```bash
curl -sS -i -X POST http://localhost:3000/api/books \
-H 'Content-Type: application/json' \
--data-binary 'invalid-json'
```

4. HTTP статус болон JSON хариуг шалгана.

## Хүлээгдсэн үр дүн

Буруу JSON биетэй POST хүсэлтэд сервер `HTTP 400 Bad Request` буцаах ёстой.

## Бодит үр дүн

Сервер `HTTP/1.1 200 OK` болон `{"result":"OK"}` буцаасан.

Туршилтыг давтан хийхэд ижил үр дүн гарсан.

**Ноцтой байдал:** Major — API буруу оролтыг амжилттай хүсэлт гэж хүлээн авч байна.

**Олдсон аялал:** Saboteur
