## 7. Дүгнэлт

Энэ лабораторид Уншлагын жагсаалт аппыг exploratory тестийн аргаар шалгасан. Хоосон талбар болон буруу оролтыг туршихад хэд хэдэн согог илэрсэн тул Couch Potato аялал үр дүнтэй байсан. Supermodel аяллаар Устгах товчны өнгө шаардлагад нийцээгүйг ажигласан. Saboteur аяллаар API-д буруу JSON илгээхэд HTTP 400-ийн оронд HTTP 200 буцаж байгааг илрүүлсэн. Анхны төлөвлөгөөнөөс гадна оныг таслалтай харуулах болон давхардсан өгөгдлийн асуудлыг ажигласан. Урт гарчиг оруулахад хүснэгтийн мөрийн өндөр нэмэгдсэн ч байрлал ноцтой эвдэрсэнгүй. Дараагийн session-д олон номтой үед хайлт, устгал болон тоолуурын ажиллагааг илүү дэлгэрэнгүй шалгах шаардлагатай.  Харин Устгах товчны өнгө болон интерфейсийн харагдах байдлын асуудлыг хүний нүдээр шууд ажиглахад илүү хялбар байсан. Энэ ажлаас тестийн төлөвлөгөө, бодит ажиглалт болон нотолгоог хооронд нь уялдуулж бичихийн ач холбогдлыг ойлгосон.
